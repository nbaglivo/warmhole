# warmhole Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A self-hosted Hono + Fedify server that turns a static site's feed into a followable fediverse account, triggered by a ping from the site's deploy.

**Architecture:** One Node process. Hono serves our own routes (WebFinger, sync ping, health) and mounts Fedify as middleware for every ActivityPub route. A pure `diff` decides what changed in the feed; `store` persists keys, followers and posts in one SQLite file that Fedify's KV store and message queue share.

**Tech Stack:** Node 26 (native TypeScript type stripping, `node:sqlite`, `node:test`), Hono 4, `@hono/node-server`, Fedify 2.4 (`@fedify/fedify`, `@fedify/vocab`, `@fedify/hono`, `@fedify/sqlite`), LogTape, feedsmith 3.

**Spec:** `docs/superpowers/specs/2026-10-15-warmhole-design.md` (visual version: `docs/design.html`)

## Global Constraints

- Node 26, pinned in `mise.toml` as `node = "26"`. Run TypeScript directly with `node`; no build step, no bundler.
- TypeScript must be erasable-only (no enums, namespaces, parameter properties). Relative imports use the `.ts` extension.
- Tests use `node:test` and `node:assert/strict`, colocated as `src/*.test.ts`. Shared test helpers live in `test/`.
- JSON files (config, `package.json`, `tsconfig.json`) contain no comments.
- Conventional commits, lowercase (`feat:`, `fix:`, `chore:`, `test:`, `docs:`). Every commit message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Never push. The human pushes.
- Config file path: env `WARMHOLE_CONFIG`, default `./warmhole.json`. Database: env `WARMHOLE_DB`, default `./data/warmhole.db`. Port: env `PORT`, default `8080`.
- Feed fetch: 10 s timeout, 5 MB limit, `Cache-Control: no-cache`, `?_=<timestamp>`.
- Sync responses: `200 { "new": n, "updated": n, "deleted": n }`; fetch or parse failure `502`; guard failure `422`; bad or missing token and unknown site `401`.
- Actor paths: `/users/{siteId}`, inbox `/users/{siteId}/inbox`, shared inbox `/inbox`, outbox `/users/{siteId}/outbox`, followers `/users/{siteId}/followers`, posts `/users/{siteId}/posts/{slug}`.
- Handles are unique per instance. WebFinger is our own Hono handler, never Fedify's.

## Review Focus

- **Feed items without a guid/id**: entries fall back to their URL as id; entries with neither are skipped instead of crashing the sync. Test in Task 2.
- **Missing or odd dates** (RFC 822, ISO 8601, absent): `published` falls back to `updated`, then to the sync time, and never becomes `Invalid Date`. Test in Task 2.
- **Relative links and images in post HTML** (`<img src="/img.png">`): resolved against the entry URL, so images show on Mastodon. Test in Task 2.
- **Several posts whose URLs end in `index.html`** (`/2026/a/index.html`, `/2026/b/index.html`): get distinct slugs (`a`, `b`), never a collision. Test in Task 4.
- **WebFinger resource variants**: `acct:` prefix missing, uppercase host, the server's own host, or the actor URL all resolve to the right site. Test in Task 7.

```ts
import { readFileSync } from 'node:fs'

export type SiteConfig = {
  id: string
  handle: string
  domain: string
  feedUrl: URL
  name: string
  summary: string | undefined
  icon: URL | undefined
  syncToken: string
  deleteMissing: boolean
}

export type Config = { publicUrl: URL; sites: SiteConfig[] }

export type Env = Record<string, string | undefined>

export class ConfigError extends Error {
  name = 'ConfigError'
}

const ID = /^[a-z0-9][a-z0-9-]*$/
const HANDLE = /^[a-z0-9_]+$/
const HOSTNAME = /^(?=.{1,253}$)([a-z0-9]([a-z0-9-]*[a-z0-9])?\.)+[a-z0-9]([a-z0-9-]*[a-z0-9])?$/

function isRecord(value: unknown): value is Record<string, unknown> {
  return typeof value === 'object' && value !== null && !Array.isArray(value)
}

function requiredString(obj: Record<string, unknown>, key: string, at: string): string {
  const value = obj[key]
  if (typeof value !== 'string' || value.trim() === '') throw new ConfigError(`${at}.${key} is required`)
  return value.trim()
}

function optionalString(obj: Record<string, unknown>, key: string, at: string): string | undefined {
  const value = obj[key]
  if (value === undefined) return undefined
  if (typeof value !== 'string') throw new ConfigError(`${at}.${key} must be a string`)
  return value
}

function secureUrl(value: unknown, field: string): URL {
  if (typeof value !== 'string') throw new ConfigError(`${field} is required`)
  let url: URL
  try {
    url = new URL(value)
  } catch {
    throw new ConfigError(`${field} is not a valid URL: ${value}`)
  }
  const local = url.hostname === 'localhost' || url.hostname === '127.0.0.1'
  if (url.protocol !== 'https:' && !(local && url.protocol === 'http:')) {
    throw new ConfigError(`${field} must use https: ${value}`)
  }
  return url
}

export function parseConfig(raw: unknown, env: Env): Config {
  if (!isRecord(raw)) throw new ConfigError('config must be a JSON object')

  const publicUrl = secureUrl(raw.publicUrl, 'publicUrl')
  if (publicUrl.pathname !== '/' || publicUrl.search !== '') {
    throw new ConfigError('publicUrl must not have a path or query')
  }

  if (!Array.isArray(raw.sites) || raw.sites.length === 0) throw new ConfigError('sites must be a non-empty array')

  const ids = new Set<string>()
  const handles = new Set<string>()

  const sites = raw.sites.map((entry: unknown, i: number): SiteConfig => {
    const at = `sites[${i}]`
    if (!isRecord(entry)) throw new ConfigError(`${at} must be an object`)

    const id = requiredString(entry, 'id', at)
    if (!ID.test(id)) throw new ConfigError(`${at}.id must match ${ID}`)
    if (ids.has(id)) throw new ConfigError(`${at}.id duplicates "${id}"`)
    ids.add(id)

    const handle = requiredString(entry, 'handle', at).toLowerCase()
    if (!HANDLE.test(handle)) throw new ConfigError(`${at}.handle must match ${HANDLE}`)
    if (handles.has(handle)) throw new ConfigError(`${at}.handle duplicates "${handle}"`)
    handles.add(handle)

    const domain = requiredString(entry, 'domain', at).toLowerCase()
    if (!HOSTNAME.test(domain)) throw new ConfigError(`${at}.domain must be a hostname like blog.example.dev`)

    const feedUrl = secureUrl(entry.feedUrl, `${at}.feedUrl`)
    const name = requiredString(entry, 'name', at)
    const summary = optionalString(entry, 'summary', at)
    const icon = entry.icon === undefined ? undefined : secureUrl(entry.icon, `${at}.icon`)

    const tokenEnv = requiredString(entry, 'syncTokenEnv', at)
    const syncToken = env[tokenEnv]
    if (!syncToken) throw new ConfigError(`${at}.syncTokenEnv: environment variable ${tokenEnv} is not set`)

    if (entry.deleteMissing !== undefined && typeof entry.deleteMissing !== 'boolean') {
      throw new ConfigError(`${at}.deleteMissing must be true or false`)
    }

    return { id, handle, domain, feedUrl, name, summary, icon, syncToken, deleteMissing: entry.deleteMissing === true }
  })

  return { publicUrl, sites }
}

export function loadConfig(path: string, env: Env = process.env): Config {
  let raw: unknown
  try {
    raw = JSON.parse(readFileSync(path, 'utf-8'))
  } catch (error) {
    throw new ConfigError(`could not read config at ${path}: ${(error as Error).message}`)
  }
  return parseConfig(raw, env)
}
```

```ts
import { parseFeed } from 'feedsmith'

export type FeedEntry = {
  id: string
  url: string
  title: string
  summary: string | null
  html: string
  published: Date
  updated: Date
}

export type FetchFeedOptions = { timeoutMs?: number; maxBytes?: number }

export class FeedError extends Error {
  name = 'FeedError'
}

type RssItem = {
  title?: string
  link?: string
  guid?: string | { value?: string; isPermaLink?: boolean }
  description?: string
  pubDate?: string
  content?: { encoded?: string }
}
type AtomText = string | { value?: string }
type AtomEntry = {
  id?: string
  title?: AtomText
  links?: { href?: string; rel?: string }[]
  summary?: AtomText
  content?: AtomText
  published?: string
  updated?: string
}
type JsonItem = {
  id?: string
  url?: string
  external_url?: string
  title?: string
  summary?: string
  content_html?: string
  content_text?: string
  date_published?: string
  date_modified?: string
}

function text(value: unknown): string | undefined {
  if (typeof value === 'string') return value
  if (typeof value === 'object' && value !== null && 'value' in value && typeof value.value === 'string') return value.value
  return undefined
}

function parseDate(value: string | undefined): Date | undefined {
  if (!value) return undefined
  const date = new Date(value)
  return Number.isNaN(date.getTime()) ? undefined : date
}

function escapeHtml(value: string): string {
  return value.replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/>/g, '&gt;')
}

function absolutize(html: string, base: string): string {
  return html.replace(/(\s(?:href|src)=)(["'])([^"']*)\2/gi, (match, attr: string, quote: string, value: string) => {
    if (value === '' || value.startsWith('#')) return match
    try {
      return `${attr}${quote}${new URL(value, base).href}${quote}`
    } catch {
      return match
    }
  })
}

type Draft = {
  id: string | undefined
  url: string | undefined
  title: string | undefined
  summary: string | undefined
  html: string | undefined
  published: string | undefined
  updated: string | undefined
}

function fromRss(item: RssItem): Draft {
  const guid = typeof item.guid === 'string' ? { value: item.guid } : item.guid
  const encoded = item.content?.encoded
  const permalink = guid?.isPermaLink !== false ? guid?.value : undefined
  return {
    id: guid?.value,
    url: item.link ?? (permalink?.startsWith('http') ? permalink : undefined),
    title: item.title,
    summary: encoded ? item.description : undefined,
    html: encoded ?? item.description,
    published: item.pubDate,
    updated: undefined,
  }
}

function fromAtom(entry: AtomEntry): Draft {
  const link = entry.links?.find((l) => !l.rel || l.rel === 'alternate')?.href
  return {
    id: entry.id,
    url: link,
    title: text(entry.title),
    summary: text(entry.summary),
    html: text(entry.content) ?? text(entry.summary),
    published: entry.published,
    updated: entry.updated,
  }
}

function fromJson(item: JsonItem): Draft {
  return {
    id: item.id,
    url: item.url ?? item.external_url,
    title: item.title,
    summary: item.summary,
    html: item.content_html ?? (item.content_text !== undefined ? `<p>${escapeHtml(item.content_text)}</p>` : undefined),
    published: item.date_published,
    updated: item.date_modified,
  }
}

function finish(draft: Draft, now: Date): FeedEntry | undefined {
  if (!draft.url) return undefined
  const published = parseDate(draft.published) ?? parseDate(draft.updated) ?? now
  const updated = parseDate(draft.updated) ?? published
  return {
    id: draft.id || draft.url,
    url: draft.url,
    title: draft.title?.trim() || draft.url,
    summary: draft.summary?.trim() || null,
    html: absolutize(draft.html ?? '', draft.url),
    published,
    updated,
  }
}

export function normalizeFeed(body: string, now: Date = new Date()): FeedEntry[] {
  let parsed: ReturnType<typeof parseFeed>
  try {
    parsed = parseFeed(body)
  } catch (error) {
    throw new FeedError(`could not parse feed: ${(error as Error).message}`)
  }

  let drafts: Draft[]
  if (parsed.format === 'rss') {
    drafts = ((parsed.feed as { items?: RssItem[] }).items ?? []).map(fromRss)
  } else if (parsed.format === 'atom') {
    drafts = ((parsed.feed as { entries?: AtomEntry[] }).entries ?? []).map(fromAtom)
  } else if (parsed.format === 'json') {
    drafts = ((parsed.feed as { items?: JsonItem[] }).items ?? []).map(fromJson)
  } else {
    throw new FeedError(`unsupported feed format: ${parsed.format}`)
  }

  return drafts.map((d) => finish(d, now)).filter((e): e is FeedEntry => e !== undefined)
}

export async function fetchFeed(url: URL, { timeoutMs = 10_000, maxBytes = 5 * 1024 * 1024 }: FetchFeedOptions = {}): Promise<string> {
  const target = new URL(url)
  target.searchParams.set('_', Date.now().toString())

  try {
    const response = await fetch(target, {
      headers: {
        'Cache-Control': 'no-cache',
        Pragma: 'no-cache',
        Accept: 'application/rss+xml, application/atom+xml, application/feed+json, application/json;q=0.9, application/xml;q=0.9, */*;q=0.8',
      },
      signal: AbortSignal.timeout(timeoutMs),
    })
    if (!response.ok) throw new FeedError(`fetching ${url.href} returned ${response.status}`)
    if (!response.body) throw new FeedError(`fetching ${url.href} returned no body`)

    const reader = response.body.getReader()
    const chunks: Uint8Array[] = []
    let size = 0
    for (;;) {
      const { done, value } = await reader.read()
      if (done) break
      size += value.byteLength
      if (size > maxBytes) {
        await reader.cancel()
        throw new FeedError(`feed is larger than ${maxBytes} bytes`)
      }
      chunks.push(value)
    }
    return Buffer.concat(chunks).toString('utf-8')
  } catch (error) {
    if (error instanceof FeedError) throw error
    throw new FeedError(`could not fetch ${url.href}: ${(error as Error).message}`)
  }
}
```

```ts
import { createHash } from 'node:crypto'
import type { FeedEntry } from './feed.ts'

export type StoredPost = { entryId: string; contentHash: string; deleted: boolean }

export type Changes = { create: FeedEntry[]; update: FeedEntry[]; delete: string[]; silent: boolean }

export class GuardError extends Error {
  name = 'GuardError'
  status = 422 as const
}

export function contentHash(entry: FeedEntry): string {
  return createHash('sha256').update(JSON.stringify([entry.title, entry.summary, entry.html, entry.url])).digest('hex')
}

export function diff(stored: StoredPost[], entries: FeedEntry[], { deleteMissing }: { deleteMissing: boolean }): Changes {
  if (entries.length === 0) throw new GuardError('feed has no entries')

  const unique = new Map<string, FeedEntry>()
  for (const e of entries) if (!unique.has(e.id)) unique.set(e.id, e)

  if (stored.length === 0) {
    return { create: [...unique.values()], update: [], delete: [], silent: true }
  }

  const byId = new Map(stored.map((p) => [p.entryId, p]))
  const create: FeedEntry[] = []
  const update: FeedEntry[] = []

  for (const e of unique.values()) {
    const post = byId.get(e.id)
    if (!post) create.push(e)
    else if (!post.deleted && post.contentHash !== contentHash(e)) update.push(e)
  }

  const active = stored.filter((p) => !p.deleted)
  const removed = deleteMissing ? active.filter((p) => !unique.has(p.entryId)).map((p) => p.entryId) : []

  if (removed.length * 2 > active.length) {
    throw new GuardError(`sync would delete ${removed.length} of ${active.length} posts; refusing`)
  }

  return { create, update, delete: removed, silent: false }
}
```

```ts
import type { DatabaseSync } from 'node:sqlite'
import { contentHash, type Changes } from './diff.ts'

export type PendingActivity = 'Create' | 'Update' | 'Delete'

export type PostRow = {
  siteId: string
  entryId: string
  slug: string
  title: string
  summary: string | null
  html: string
  url: string
  published: string
  updated: string
  contentHash: string
  deletedAt: string | null
  pendingActivity: PendingActivity | null
}

export type Follower = { actorId: string; inbox: string; sharedInbox: string | null }

export type StoredKey = { kind: 'rsa' | 'ed25519'; privateJwk: JsonWebKey; publicJwk: JsonWebKey }

export type Page = { offset: number; limit: number }

const SCHEMA = `
CREATE TABLE IF NOT EXISTS keys (
  site_id TEXT NOT NULL,
  kind TEXT NOT NULL,
  private_jwk TEXT NOT NULL,
  public_jwk TEXT NOT NULL,
  PRIMARY KEY (site_id, kind)
);
CREATE TABLE IF NOT EXISTS followers (
  site_id TEXT NOT NULL,
  actor_id TEXT NOT NULL,
  inbox TEXT NOT NULL,
  shared_inbox TEXT,
  created_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now')),
  PRIMARY KEY (site_id, actor_id)
);
CREATE TABLE IF NOT EXISTS posts (
  site_id TEXT NOT NULL,
  entry_id TEXT NOT NULL,
  slug TEXT NOT NULL,
  title TEXT NOT NULL,
  summary TEXT,
  html TEXT NOT NULL,
  url TEXT NOT NULL,
  published TEXT NOT NULL,
  updated TEXT NOT NULL,
  content_hash TEXT NOT NULL,
  deleted_at TEXT,
  pending_activity TEXT,
  PRIMARY KEY (site_id, entry_id),
  UNIQUE (site_id, slug)

export function slugFor(url: string, taken: Set<string>): string {
  const segments = new URL(url).pathname
    .split('/')
    .filter(Boolean)
    .map((s) => decodeURIComponent(s).replace(/\.[a-z0-9]+$/i, ''))
  const meaningful = segments.filter((s) => s.toLowerCase() !== 'index')
  const base =
    (meaningful.at(-1) ?? '')
      .toLowerCase()
      .replace(/[^a-z0-9]+/g, '-')
      .replace(/^-+|-+$/g, '') || 'post'
  let slug = base
  for (let n = 2; taken.has(slug); n++) slug = `${base}-${n}`
  return slug
}

type Row = Record<string, unknown>

function toPost(row: Row): PostRow {
  return {
    siteId: row.site_id as string,
    entryId: row.entry_id as string,
    slug: row.slug as string,
    title: row.title as string,
    summary: (row.summary as string | null) ?? null,
    html: row.html as string,
    url: row.url as string,
    published: row.published as string,
    updated: row.updated as string,
    contentHash: row.content_hash as string,
    deletedAt: (row.deleted_at as string | null) ?? null,
    pendingActivity: (row.pending_activity as PendingActivity | null) ?? null,
  }
}

function toFollower(row: Row): Follower {
  return { actorId: row.actor_id as string, inbox: row.inbox as string, sharedInbox: (row.shared_inbox as string | null) ?? null }
}

export class Store {
  db: DatabaseSync

  constructor(db: DatabaseSync) {
    this.db = db
  }

  migrate(): void {
    this.db.exec('PRAGMA journal_mode = WAL')
    this.db.exec(SCHEMA)
  }

  transaction<T>(fn: () => T): T {
    this.db.exec('BEGIN')
    try {
      const result = fn()
      this.db.exec('COMMIT')
      return result
    } catch (error) {
      this.db.exec('ROLLBACK')
      throw error
    }
  }

  getKeys(siteId: string): StoredKey[] {
    return this.db
      .prepare('SELECT kind, private_jwk, public_jwk FROM keys WHERE site_id = ? ORDER BY kind DESC')
      .all(siteId)
      .map((row) => ({
        kind: row.kind as StoredKey['kind'],
        privateJwk: JSON.parse(row.private_jwk as string),
        publicJwk: JSON.parse(row.public_jwk as string),
      }))
  }

  saveKeys(siteId: string, keys: StoredKey[]): void {
    const insert = this.db.prepare('INSERT OR IGNORE INTO keys (site_id, kind, private_jwk, public_jwk) VALUES (?, ?, ?, ?)')
    this.transaction(() => {
      for (const k of keys) insert.run(siteId, k.kind, JSON.stringify(k.privateJwk), JSON.stringify(k.publicJwk))
    })
  }

  addFollower(siteId: string, f: Follower): void {
    this.db
      .prepare(
        `INSERT INTO followers (site_id, actor_id, inbox, shared_inbox) VALUES (?, ?, ?, ?)
         ON CONFLICT (site_id, actor_id) DO UPDATE SET inbox = excluded.inbox, shared_inbox = excluded.shared_inbox`,
      )
      .run(siteId, f.actorId, f.inbox, f.sharedInbox)
  }

  removeFollower(siteId: string, actorId: string): void {
    this.db.prepare('DELETE FROM followers WHERE site_id = ? AND actor_id = ?').run(siteId, actorId)
  }

  removeFollowersByInbox(inbox: string): number {
    return Number(this.db.prepare('DELETE FROM followers WHERE inbox = ? OR shared_inbox = ?').run(inbox, inbox).changes)
  }

  listFollowers(siteId: string, { offset, limit }: Page): Follower[] {
    return this.db
      .prepare('SELECT actor_id, inbox, shared_inbox FROM followers WHERE site_id = ? ORDER BY created_at, actor_id LIMIT ? OFFSET ?')
      .all(siteId, limit, offset)
      .map(toFollower)
  }

  countFollowers(siteId: string): number {
    return Number(this.db.prepare('SELECT count(*) AS n FROM followers WHERE site_id = ?').get(siteId)!.n)
  }

  listPosts(siteId: string): PostRow[] {
    return this.db.prepare('SELECT * FROM posts WHERE site_id = ?').all(siteId).map(toPost)
  }

  getPostBySlug(siteId: string, slug: string): PostRow | undefined {
    const row = this.db.prepare('SELECT * FROM posts WHERE site_id = ? AND slug = ?').get(siteId, slug)
    return row ? toPost(row) : undefined
  }

  listPublishedPosts(siteId: string, { offset, limit }: Page): PostRow[] {
    return this.db
      .prepare('SELECT * FROM posts WHERE site_id = ? AND deleted_at IS NULL ORDER BY published DESC, entry_id LIMIT ? OFFSET ?')
      .all(siteId, limit, offset)
      .map(toPost)
  }

  countPublishedPosts(siteId: string): number {
    return Number(this.db.prepare('SELECT count(*) AS n FROM posts WHERE site_id = ? AND deleted_at IS NULL').get(siteId)!.n)
  }

  applyChanges(siteId: string, changes: Changes, now: Date = new Date()): void {
    const taken = new Set(this.listPosts(siteId).map((p) => p.slug))
    const insert = this.db.prepare(
      `INSERT INTO posts (site_id, entry_id, slug, title, summary, html, url, published, updated, content_hash, pending_activity)
       VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)`,
    )
    const update = this.db.prepare(
      `UPDATE posts SET title = ?, summary = ?, html = ?, url = ?, published = ?, updated = ?, content_hash = ?,
         pending_activity = CASE WHEN pending_activity = 'Create' THEN 'Create' ELSE 'Update' END
       WHERE site_id = ? AND entry_id = ?`,
    )
    const remove = this.db.prepare(
      `UPDATE posts SET deleted_at = ?, pending_activity = 'Delete' WHERE site_id = ? AND entry_id = ?`,
    )

    this.transaction(() => {
      for (const e of changes.create) {
        const slug = slugFor(e.url, taken)
        taken.add(slug)
        insert.run(siteId, e.id, slug, e.title, e.summary, e.html, e.url, e.published.toISOString(), e.updated.toISOString(), contentHash(e), changes.silent ? null : 'Create')
      }
      for (const e of changes.update) {
        update.run(e.title, e.summary, e.html, e.url, e.published.toISOString(), e.updated.toISOString(), contentHash(e), siteId, e.id)
      }
      for (const entryId of changes.delete) remove.run(now.toISOString(), siteId, entryId)
    })
  }

  listPending(siteId: string): PostRow[] {
    return this.db
      .prepare('SELECT * FROM posts WHERE site_id = ? AND pending_activity IS NOT NULL ORDER BY published, entry_id')
      .all(siteId)
      .map(toPost)
  }

  clearPending(siteId: string, entryId: string): void {
    this.db.prepare('UPDATE posts SET pending_activity = NULL WHERE site_id = ? AND entry_id = ?').run(siteId, entryId)
  }
}
```

```ts
import {
  createFederation,
  exportJwk,
  generateCryptoKeyPair,
  importJwk,
  type Context,
  type Federation,
  type KvStore,
  type MessageQueue,
} from '@fedify/fedify'
import {
  Accept,
  Article,
  Create,
  Delete,
  Endpoints,
  Follow,
  Image,
  Person,
  PUBLIC_COLLECTION,
  Tombstone,
  Undo,
  Update,
  isActor,
  type Activity,
  type Recipient,
} from '@fedify/vocab'
import type { Config } from './config.ts'
import type { PendingActivity, PostRow, Store, StoredKey } from './store.ts'

const PAGE_SIZE = 20

export type FederationDeps = {
  config: Config
  store: Store
  kv: KvStore
  queue?: MessageQueue
  allowPrivateAddress?: boolean
  skipSignatureVerification?: boolean
}

export function articleFor(ctx: Context<void>, siteId: string, post: PostRow): Article {
  return new Article({
    id: ctx.getObjectUri(Article, { identifier: siteId, slug: post.slug }),
    attribution: ctx.getActorUri(siteId),
    to: PUBLIC_COLLECTION,
    cc: ctx.getFollowersUri(siteId),
    name: post.title,
    summary: post.summary,
    content: post.html,
    url: new URL(post.url),
    published: Temporal.Instant.from(post.published),
    updated: post.updated !== post.published ? Temporal.Instant.from(post.updated) : null,
  })
}

export function activityFor(ctx: Context<void>, siteId: string, post: PostRow, kind: PendingActivity): Activity {
  const object = articleFor(ctx, siteId, post)
  const objectId = object.id!
  const shared = { actor: ctx.getActorUri(siteId), to: PUBLIC_COLLECTION, cc: ctx.getFollowersUri(siteId) }
  if (kind === 'Create') {
    return new Create({ ...shared, id: new URL('#create', objectId), object, published: object.published })
  }
  if (kind === 'Update') {
    return new Update({ ...shared, id: new URL(`#update-${post.contentHash.slice(0, 12)}`, objectId), object, updated: Temporal.Now.instant() })
  }
  return new Delete({ ...shared, id: new URL('#delete', objectId), object: new Tombstone({ id: objectId }) })
}

async function generateKeys(): Promise<StoredKey[]> {
  const rsa = await generateCryptoKeyPair('RSASSA-PKCS1-v1_5')
  const ed = await generateCryptoKeyPair('Ed25519')
  return [
    { kind: 'rsa', privateJwk: await exportJwk(rsa.privateKey), publicJwk: await exportJwk(rsa.publicKey) },
    { kind: 'ed25519', privateJwk: await exportJwk(ed.privateKey), publicJwk: await exportJwk(ed.publicKey) },
  ]
}

function nextCursor(offset: number, total: number): string | null {
  return offset + PAGE_SIZE < total ? String(offset + PAGE_SIZE) : null
}

export function buildFederation({ config, store, kv, queue, allowPrivateAddress = false, skipSignatureVerification = false }: FederationDeps): Federation<void> {
  const sites = new Map(config.sites.map((s) => [s.id, s]))

  const federation = createFederation<void>({
    kv,
    queue,
    manuallyStartQueue: queue !== undefined,
    origin: config.publicUrl.origin,
    allowPrivateAddress,
    skipSignatureVerification,
  })

  federation
    .setActorDispatcher('/users/{identifier}', async (ctx, identifier) => {
      const site = sites.get(identifier)
      if (!site) return null
      const keys = await ctx.getActorKeyPairs(identifier)
      return new Person({
        id: ctx.getActorUri(identifier),
        preferredUsername: site.handle,
        name: site.name,
        summary: site.summary ?? null,
        url: new URL(`https://${site.domain}/`),
        icon: site.icon ? new Image({ url: site.icon }) : null,
        inbox: ctx.getInboxUri(identifier),
        outbox: ctx.getOutboxUri(identifier),
        followers: ctx.getFollowersUri(identifier),
        endpoints: new Endpoints({ sharedInbox: ctx.getInboxUri() }),
        publicKey: keys[0]?.cryptographicKey,
        assertionMethods: keys.map((k) => k.multikey),
        manuallyApprovesFollowers: false,
        discoverable: true,
      })
    })
    .setKeyPairsDispatcher(async (_ctx, identifier) => {
      if (!sites.has(identifier)) return []
      if (store.getKeys(identifier).length === 0) store.saveKeys(identifier, await generateKeys())
      return Promise.all(
        store.getKeys(identifier).map(async (k) => ({
          privateKey: await importJwk(k.privateJwk, 'private'),
          publicKey: await importJwk(k.publicJwk, 'public'),
        })),
      )
    })

  federation
    .setOutboxDispatcher('/users/{identifier}/outbox', (ctx, identifier, cursor) => {
      if (!sites.has(identifier) || cursor === null) return null
      const offset = Number(cursor) || 0
      const posts = store.listPublishedPosts(identifier, { offset, limit: PAGE_SIZE })
      return {
        items: posts.map((p) => activityFor(ctx, identifier, p, 'Create')),
        nextCursor: nextCursor(offset, store.countPublishedPosts(identifier)),
      }
    })
    .setCounter((_ctx, identifier) => (sites.has(identifier) ? store.countPublishedPosts(identifier) : null))
    .setFirstCursor(() => '0')

  federation
    .setFollowersDispatcher('/users/{identifier}/followers', (_ctx, identifier, cursor) => {
      if (!sites.has(identifier) || cursor === null) return null
      const offset = Number(cursor) || 0
      const items: Recipient[] = store.listFollowers(identifier, { offset, limit: PAGE_SIZE }).map((f) => ({
        id: new URL(f.actorId),
        inboxId: new URL(f.inbox),
        endpoints: f.sharedInbox ? { sharedInbox: new URL(f.sharedInbox) } : null,
      }))
      return { items, nextCursor: nextCursor(offset, store.countFollowers(identifier)) }
    })
    .setCounter((_ctx, identifier) => (sites.has(identifier) ? store.countFollowers(identifier) : null))
    .setFirstCursor(() => '0')

  federation.setObjectDispatcher(Article, '/users/{identifier}/posts/{slug}', (ctx, { identifier, slug }) => {
    const post = store.getPostBySlug(identifier, slug)
    if (!post) return null
    if (post.deletedAt) {
      return new Tombstone({ id: ctx.getObjectUri(Article, { identifier, slug }), deleted: Temporal.Instant.from(post.deletedAt) })
    }
    return articleFor(ctx, identifier, post)
  })

  federation
    .setInboxListeners('/users/{identifier}/inbox', '/inbox')
    .on(Follow, async (ctx, follow) => {
      if (follow.id === null || follow.objectId === null) return
      const parsed = ctx.parseUri(follow.objectId)
      if (parsed?.type !== 'actor' || !sites.has(parsed.identifier)) return
      const follower = await follow.getActor(ctx)
      if (follower === null || !isActor(follower) || follower.id === null || follower.inboxId === null) return
      store.addFollower(parsed.identifier, {
        actorId: follower.id.href,
        inbox: follower.inboxId.href,
        sharedInbox: follower.endpoints?.sharedInbox?.href ?? null,
      })
      await ctx.sendActivity(
        { identifier: parsed.identifier },
        follower,
        new Accept({
          id: new URL(`#accepts/${crypto.randomUUID()}`, ctx.getActorUri(parsed.identifier)),
          actor: follow.objectId,
          object: follow,
        }),
      )
    })
    .on(Undo, async (ctx, undo) => {
      const object = await undo.getObject(ctx)
      if (!(object instanceof Follow) || undo.actorId === null || object.objectId === null) return
      const parsed = ctx.parseUri(object.objectId)
      if (parsed?.type !== 'actor' || !sites.has(parsed.identifier)) return
      store.removeFollower(parsed.identifier, undo.actorId.href)
    })

  federation.setOutboxPermanentFailureHandler((_ctx, { inbox }) => {
    store.removeFollowersByInbox(inbox.href)
  })

  return federation
}
```

```ts
import type { Federation } from '@fedify/fedify'
import type { Config } from './config.ts'
import { fetchFeed as defaultFetchFeed, normalizeFeed } from './feed.ts'
import { diff } from './diff.ts'
import type { Store } from './store.ts'
import { activityFor } from './federation.ts'

export type SyncResult = { new: number; updated: number; deleted: number }

export type SyncDeps = {
  config: Config
  store: Store
  federation: Federation<void>
  fetchFeed?: (url: URL) => Promise<string>
}

export class UnknownSiteError extends Error {
  name = 'UnknownSiteError'
}

export class Syncer {
  deps: SyncDeps
  locks = new Map<string, Promise<unknown>>()

  constructor(deps: SyncDeps) {
    this.deps = deps
  }

  async sync(siteId: string): Promise<SyncResult> {
    const previous = this.locks.get(siteId) ?? Promise.resolve()
    const run = previous.catch(() => undefined).then(() => this.run(siteId))
    this.locks.set(siteId, run)
    try {
      return await run
    } finally {
      if (this.locks.get(siteId) === run) this.locks.delete(siteId)
    }
  }

  async run(siteId: string): Promise<SyncResult> {
    const { config, store } = this.deps
    const site = config.sites.find((s) => s.id === siteId)
    if (!site) throw new UnknownSiteError(`unknown site ${siteId}`)

    const fetchFeed = this.deps.fetchFeed ?? defaultFetchFeed
    const entries = normalizeFeed(await fetchFeed(site.feedUrl))
    const stored = store.listPosts(siteId).map((p) => ({ entryId: p.entryId, contentHash: p.contentHash, deleted: p.deletedAt !== null }))
    const changes = diff(stored, entries, { deleteMissing: site.deleteMissing })

    store.applyChanges(siteId, changes)
    await this.flushPending(siteId)

    return { new: changes.create.length, updated: changes.update.length, deleted: changes.delete.length }
  }

  async flushPending(siteId: string): Promise<void> {
    const { config, store, federation } = this.deps
    const ctx = federation.createContext(config.publicUrl, undefined)
    for (const post of store.listPending(siteId)) {
      await ctx.sendActivity({ identifier: siteId }, 'followers', activityFor(ctx, siteId, post, post.pendingActivity!), { preferSharedInbox: true })
      store.clearPending(siteId, post.entryId)
    }
  }
}
```

```ts
import { createHash, timingSafeEqual } from 'node:crypto'
import { Hono } from 'hono'
import { federation as fedifyMiddleware } from '@fedify/hono'
import type { Federation } from '@fedify/fedify'
import type { Config, SiteConfig } from './config.ts'
import type { SyncResult } from './sync.ts'
import { FeedError } from './feed.ts'
import { GuardError } from './diff.ts'

export type AppDeps = {
  config: Config
  federation: Federation<void>
  syncer: { sync(siteId: string): Promise<SyncResult> }
}

function actorUrl(config: Config, site: SiteConfig): string {
  return new URL(`/users/${site.id}`, config.publicUrl).href
}

export function webfingerFor(config: Config, site: SiteConfig): Record<string, unknown> {
  const actor = actorUrl(config, site)
  return {
    subject: `acct:${site.handle}@${site.domain}`,
    aliases: [actor],
    links: [
      { rel: 'self', type: 'application/activity+json', href: actor },
      { rel: 'http://webfinger.net/rel/profile-page', type: 'text/html', href: `https://${site.domain}/` },
    ],
  }
}

export function findSiteByResource(config: Config, resource: string): SiteConfig | undefined {
  if (/^https?:\/\//i.test(resource)) {
    return config.sites.find((s) => actorUrl(config, s) === resource)
  }
  const match = /^(?:acct:)?([^@]+)@([^@]+)$/i.exec(resource.trim())
  if (!match) return undefined
  const handle = match[1].toLowerCase()
  const host = match[2].toLowerCase()
  return config.sites.find((s) => s.handle === handle && (host === s.domain || host === config.publicUrl.host))
}

function sameToken(given: string, expected: string): boolean {
  const a = createHash('sha256').update(given).digest()
  const b = createHash('sha256').update(expected).digest()
  return timingSafeEqual(a, b)
}

export function buildApp({ config, federation, syncer }: AppDeps): Hono {
  const app = new Hono()
  const sites = new Map(config.sites.map((s) => [s.id, s]))

  app.get('/.well-known/webfinger', (c) => {
    const resource = c.req.query('resource')
    if (!resource) return c.json({ error: 'resource is required' }, 400)
    const site = findSiteByResource(config, resource)
    if (!site) return c.json({ error: 'not found' }, 404)
    return c.body(JSON.stringify(webfingerFor(config, site)), 200, {
      'content-type': 'application/jrd+json',
      'access-control-allow-origin': '*',
    })
  })

  app.get('/sites/:id/webfinger.json', (c) => {
    const site = sites.get(c.req.param('id'))
    if (!site) return c.json({ error: 'not found' }, 404)
    return c.json(webfingerFor(config, site))
  })

  app.post('/sites/:id/sync', async (c) => {
    const site = sites.get(c.req.param('id'))
    const header = c.req.header('authorization') ?? ''
    const token = header.startsWith('Bearer ') ? header.slice('Bearer '.length) : ''
    if (!site || !sameToken(token, site.syncToken)) return c.json({ error: 'unauthorized' }, 401)
    try {
      return c.json(await syncer.sync(site.id))
    } catch (error) {
      if (error instanceof FeedError) return c.json({ error: error.message }, 502)
      if (error instanceof GuardError) return c.json({ error: error.message }, 422)
      throw error
    }
  })

  app.get('/healthz', (c) => c.text('ok'))

  app.use(fedifyMiddleware(federation, () => undefined))

  return app
}
```

- [ ] **Step 3: Rewrite `README.md`**

````markdown
# warmhole

A warm little portal from your static site into the fediverse.

warmhole is a small, self-hosted server that turns your site's feed into a
fediverse account. People follow `@you@your-site.dev` from Mastodon, and each
new post shows up in their timeline. Your site stays static.

## How it works

Your site keeps publishing its RSS, Atom or JSON Feed. After each deploy, it
pings warmhole. warmhole reads the feed, works out what's new, edited or
removed, and sends it to your followers. Follows are accepted automatically.
Likes, boosts and replies are ignored for now.

Design and diagrams: [`docs/design.html`](docs/design.html).

## Run it

1. Copy `warmhole.example.json` to `warmhole.json` and fill in one entry per
   site. `syncTokenEnv` names an environment variable holding a long random
   token for that site.
2. Run the container, with the database on a volume you back up (it holds
   each site's private keys):

   ```bash
   docker build -t warmhole .
   docker run -d -p 8080:8080 \
     -e MY_BLOG_SYNC_TOKEN="$(openssl rand -hex 32)" \
     -v "$PWD/warmhole.json:/config/warmhole.json:ro" \
     -v warmhole-data:/data \
     warmhole
   ```

3. Put it behind HTTPS at the `publicUrl` from your config.

Without Docker: `mise install && npm ci && npm start`. Settings come from
`WARMHOLE_CONFIG` (default `./warmhole.json`), `WARMHOLE_DB` (default
`./data/warmhole.db`) and `PORT` (default `8080`).

## Connect a site

1. **WebFinger.** Download `https://<publicUrl>/sites/<id>/webfinger.json` and
   publish it on your site at `/.well-known/webfinger`, served as
   `application/jrd+json`. On Cloudflare Pages, add to `_headers`:

   ```
   /.well-known/webfinger
     Content-Type: application/jrd+json
     Access-Control-Allow-Origin: *
   ```

2. **Ping after deploy.** In GitHub Actions:

   ```yaml
   - name: Notify warmhole
     run: >
       curl --fail --retry 3 -X POST
       -H "Authorization: Bearer ${{ secrets.WARMHOLE_SYNC_TOKEN }}"
       https://ap.example.dev/sites/my-blog/sync
   ```

   The response says what happened, for example
   `{"new":1,"updated":0,"deleted":0}`. Pinging again is always safe.

The first ping for a site saves the existing posts without sending them, so new
followers aren't flooded.

## Check it works

- `npx @fedify/cli lookup @you@your-site.dev` should show your actor.
- `npx @fedify/cli inbox` gives you a throwaway account to follow from.
- Then follow from a real Mastodon account, publish a post and ping.

## Development

```bash
npm test
npm run typecheck
```
````
